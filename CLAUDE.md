## Claude Code study commands

This repository ships project skills in `.claude/skills/`. Students invoke them as slash
commands; you may also use the matching skill when a student's request clearly fits one.

| Command | Use it to |
|---|---|
| `/tutor <topic>` | Learn a concept from first principles, Socratically |
| `/hint <lab> [exercise]` | Get unstuck on a lab exercise one hint level at a time |
| `/review-my-code <file>` | Get feedback on your own lab/capstone code without it being rewritten |
| `/quiz-me [module]` | Retrieval practice that adapts to what you got wrong last time |
| `/explain-back <topic>` | Feynman technique: you explain, Claude finds the gaps |
| `/mock-interview [prompt]` | A timed 45-minute ML system design interview, scored with the course rubric |

The full student guide is [`docs/ai-assisted-learning.md`](docs/ai-assisted-learning.md).
